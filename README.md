# Budget-Tracker
A gamified personal budgeting app rooted in the biblical stewardship framework (Live, Give, Owe, Grow).

## Acknowledgements & Attributions

### Code & Framework
* **Biblical Financial Framework:** Based on the *Live, Give, Owe, Grow* financial stewardship model developed by Ron Blue.
* **Code & Development:** Co-authored and developed in collaboration with Claude (Anthropic).
* **Styling Framework:** [Tailwind CSS](https://tailwindcss.com/) via CDN.
* **Audio:** Synthesized sound effects generated natively using the Web Audio API.
