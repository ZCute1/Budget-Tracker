# Budget-Tracker
## ✿ Live · Give · Owe · Grow — Budget Tracker

A gamified, interactive personal budgeting web app rooted in Ron Blue's biblical financial stewardship framework.

🔗 **[Try the Live App Here](https://zcute1.github.io/Budget-Tracker/)**

---

## ✨ Features

* **Biblical Stewardship Framework:** Categorize spending into the four core biblical buckets: **Live**, **Give**, **Owe**, and **Grow** (*"God owns it all"*).
* **Gamified Transaction Sorting:** Swipe, tap, or use arrow keys to sort incoming bank statements and expenses.
* **Goals & Safe-to-Spend Tracker:** Set monthly income and bucket targets to calculate essential living expenses, monthly flex left, and weekly safe-to-spend allowances.
* **Gamified Visual Feedback:**
  * **Daily Tip Jar:** Fills with coins as you designate money toward savings.
  * **Investment Garden:** Spawns blooming flowers based on investment contributions.
  * **Customizable Companion Avatars:** Pick or upload transparent avatars that cheer, offer sassy commentary, and track your streaks.
* **Audio & Effects:** Native Web Audio chimes and milestone melodies.
* **100% Client-Side Privacy:** All CSV/statement parsing and transaction data remain securely inside the browser via `localStorage`—no data leaves your machine.

---

## 🚀 How to Use

1. Visit the [Live Site](https://zcute1.github.io/Budget-Tracker/).
2. Click **Try demo data** or drop in your own bank export CSV.
3. Use the arrow keys or buttons to sort your transactions into the four categories.
4. Open the **Goals** tab to configure your income, fixed costs, and flex budget.
